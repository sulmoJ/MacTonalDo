# macTonaldo

맥북 메뉴바에 사는 로컬 투두 앱. 아이콘을 누르면 아래로 패널이 열리고,
그 안에서 할 일 · 하위 할 일 · 메모를 바로 관리한다.
할 일은 **날짜별로 나뉘며 패널을 열면 늘 오늘부터** 보여 준다.
**데일리 스크럼** 글도 한 번에 만들어 복사할 수 있다.
네트워크를 쓰지 않고 모든 데이터는 이 맥 안에만 있다.

이름은 mac 과 맥도날드를 붙여 지었다. 하는 일과는 상관없다.

## 빌드와 실행

```bash
./build.sh
open build/macTonaldo.app
```

Xcode 없이 Command Line Tools 의 `swiftc` 만으로 빌드한다.
`build/macTonaldo.app` 을 `/Applications` 로 옮겨 두면 평소처럼 쓸 수 있다.

```bash
cp -R build/macTonaldo.app /Applications/
```

## 쓰는 법

| 하고 싶은 것 | 방법 |
| --- | --- |
| 할 일 추가 | 패널 위쪽 입력창에 쓰고 Enter (지금 보고 있는 날짜에 붙는다) |
| 날짜 넘기기 | 날짜 띠의 `‹` `›` (⌘[ / ⌘]) |
| 오늘로 돌아가기 | 날짜 띠 오른쪽 달력 아이콘 (⌘T) — 패널을 다시 열어도 오늘로 돌아온다 |
| 할 일을 다른 날로 | 우클릭 → `날짜 옮기기` → 어제/오늘/내일, 또는 하루 앞뒤로 |
| 지난 미완료 끌어오기 | 오늘 화면 위에 뜨는 띠의 `오늘로 가져오기` |
| 데일리 스크럼 | 머리말의 `scrum` 버튼 (⌘D) |
| 작업일 범위 바꾸기 | 오른쪽 위 `⋯` → `작업일 범위` → 월~금 / 월~일 |
| 완료 / 해제 | 왼쪽 동그라미 클릭 |
| 제목 고치기 | 제목을 클릭하면 입력창으로 바뀜 (Enter 로 확정, Esc 로 취소) |
| 하위 할 일 추가 | 줄에 마우스를 올리면 나오는 `+`, 또는 우클릭 메뉴 |
| 하위 할 일 연달아 추가 | 입력창이 열린 채로 남으므로 Enter 로 계속 입력 |
| 메모 추가 | 우클릭 → `메모 추가` |
| 접기 / 펼치기 | 제목 왼쪽 `›` 클릭 |
| 순서 바꾸기 | 마우스를 올리면 왼쪽에 나오는 손잡이를 끌어서 이동 (우클릭 메뉴로도 가능) |
| 우선순위 정하기 | 우클릭 → `우선순위` → 높음/보통/낮음/없음 |
| 우선순위 빠르게 바꾸기 | 제목 앞 깃발 클릭 (높음 → 보통 → 낮음 → 없음 순환) |
| 삭제 | 우클릭 → `삭제` (하위 할 일은 마우스 올렸을 때 `✕`) |
| 완료한 항목 숨기기 | 오른쪽 위 `⋯` 메뉴 |
| 완료한 항목 비우기 | 오른쪽 위 `⋯` → `이 날짜의 완료 항목 삭제` |
| 우선순위 순으로 정렬 | 오른쪽 위 `⋯` → `우선순위 높은 순으로 정렬` |
| 로그인할 때 자동 실행 | 오른쪽 위 `⋯` 메뉴 |
| 공유용으로 내보내기 | 머리말 오른쪽 내보내기(↑) 버튼 |
| 종료 | 오른쪽 위 `⋯` → `종료` (⌘Q) |

동작 규칙:

- 패널을 열 때마다 보는 날짜가 **오늘**로 돌아온다. 어제를 보다 닫아도 다음에 열면 오늘이다.
- 숨기기 · 비우기 · 정렬 · 순서 바꾸기는 모두 **보고 있는 날짜 안에서만** 일어난다.
  다른 날짜는 건드리지 않는다.
- 끌어서 순서를 바꾸는 것도 같은 날짜 안에서만 된다. 날짜를 바꾸려면 우클릭 메뉴를 쓴다.
- 다른 날로 옮긴 할 일은 지금 화면에서 바로 사라진다. 그 날짜로 넘어가면 보인다.
- 상위 할 일을 체크하면 하위 할 일도 모두 체크된다.
- 하위 할 일이 전부 끝나면 상위 할 일도 자동으로 완료된다.
- 끌어서 옮길 때, 아래로 내리면 대상 **뒤**로, 위로 올리면 대상 **앞**으로 들어간다.
- `우선순위 높은 순으로 정렬` 은 한 번 실행하면 끝이고 되돌리기는 없다.
  같은 등급끼리는 지금 순서를 그대로 지킨다.

## 날짜

날짜 띠에 `오늘 · 11월 6일 (금)` 처럼 뜬다. 어제 · 그저께 · 내일 · 모레까지는
이름으로 부르고, 그 밖은 날짜만 보여 준다.

**지난 미완료.** 오늘을 보고 있을 때, 지난 날짜에 안 끝난 할 일이 남아 있으면
목록 위에 주황색 띠로 알려 준다. `오늘로 가져오기` 를 누르면 그 할 일들의
날짜가 오늘로 바뀐다. 완료한 항목은 지난 날짜에 그대로 남는다.
자동으로 옮기지는 않는다 — 누를 때만 옮긴다.

**메뉴바 숫자.** 오늘 남은 할 일과 지난 미완료를 합친 수다.
내일 이후로 미뤄 둔 할 일은 세지 않는다.

## 데일리 스크럼

머리말의 `scrum` 버튼(⌘D)을 누르면 스크럼 글 미리보기가 열린다.
`복사하기` 를 누르면 클립보드에 담기고, Esc 나 `닫기` 로 목록으로 돌아온다.

```text
완료한 일

* Todo 1
* Todo 2


진행할 일

* Todo 3
* Todo 4
```

**완료한 일** — 전 작업일부터 어제까지 완료 체크한 할 일.
**진행할 일** — 오늘 날짜의 할 일 중 아직 체크하지 않은 것.
이미 오늘 체크한 일은 "진행할 일" 이 아니므로 빼고 적는다.

하위 할 일도 한 칸 들여서 함께 적는다.
완료한 일에는 끝낸 하위만, 진행할 일에는 남은 하위만 담는다.
어느 쪽도 비어 있으면 `없음` 한 줄이 들어간다.

**지난 미완료 가져오기.** 미리보기 아래 체크박스다. 켜 두면 `복사하기` 를 누를 때
지난 날의 안 끝난 할 일이 모두 오늘로 올라오고, 미리보기의 "진행할 일" 에도 미리 비친다.
끄면 글만 복사하고 날짜는 건드리지 않는다. 기본은 켜짐이다.

### 작업일 범위

`⋯ → 작업일 범위` 에서 고른다. 전 작업일을 어디로 잡을지가 달라진다.

| 범위 | 전 작업일 |
| --- | --- |
| 월~금 | 화~금요일이면 어제. 월요일이면 **금요일** (토·일은 건너뛴다) |
| 월~일 | 늘 어제 |

완료한 일은 `전 작업일 ~ 어제` 구간을 통째로 훑는다.
그래서 월~금으로 두고 월요일에 열면 금요일뿐 아니라 **주말에 끝낸 일도 함께** 올라온다.
작업일이 아닌 날(월~금에서 토요일)에 열어도 전 작업일은 금요일로 잡힌다.

## 우선순위

네 단계다. 깃발 색으로 구분하고, 등급이 `없음` 이면 깃발을 아예 그리지 않는다.

| 등급 | 색 |
| --- | --- |
| 높음 | 빨강 |
| 보통 | 주황 |
| 낮음 | 회색 |
| 없음 | 표시 없음 |

드래그는 줄 전체가 아니라 왼쪽 손잡이에서만 시작한다.
줄 전체에 걸면 제목을 눌러 고치려다 끌려 버리기 때문이다.

## 공유용 내보내기

머리말 오른쪽 내보내기 버튼에서 고른다. 복사가 끝나면 아이콘이 잠깐 체크 표시로 바뀐다.
메뉴는 두 묶음이다.

보고 있는 날짜:

- **텍스트로 복사** — 슬랙·메신저에 그대로 붙여 넣는 용도
- **마크다운으로 복사** — 노션·깃허브·문서 도구용 체크리스트
- **남은 할 일만 복사** — 완료한 항목을 뺀 텍스트

전체 날짜:

- **마크다운으로 복사** — 날짜별로 묶어서, 지난 날이 위로
- **파일로 저장…** — `2026-11-06 할 일.md` 같은 이름으로 전체 저장

텍스트 형식:

```
11월 6일 (금) · 할 일 1/3 완료

☐ [높음] 할일 1
  ☐ 할일 1의 서브 태스크
☐ [보통] 할일 2
   ↳ 할일 2의 메모
  ☑ 할일 2의 서브태스크
☑ 메뉴바에서 바로 체크해 보기
```

마크다운 형식 (전체 날짜):

```
## 11월 5일 (목) · 할 일 1/1 완료

- [x] 어제 끝낸 일

## 11월 6일 (금) · 할 일 0/2 완료

- [ ] [높음] 할일 1
  - [ ] 할일 1의 서브 태스크
- [ ] [보통] 할일 2
  - 메모: 할일 2의 메모
```

## 데이터

```
~/Library/Application Support/macTonaldo/todos.json
```

사람이 읽을 수 있는 JSON 이라 손으로 고치거나 백업해도 된다.
변경이 멈추고 0.4초 뒤에 저장한다. `⋯ → 저장 폴더 열기` 로 바로 열 수 있다.

예전 이름이 `MenuTodo` 였다. 새 폴더에 파일이 아직 없고 옛 폴더에 있으면
첫 실행 때 한 번 베껴 온다. 옛 파일은 지우지 않고 그대로 둔다.

날짜가 없던 시절(`version 1`)에 저장된 할 일은 **전부 오늘 할 일로 읽는다.**
만든 날짜로 흩뿌리면 쓰던 목록이 과거로 사라져 버리기 때문이다.
처음 무언가를 고치는 순간 `version 2` 로 다시 저장되면서 날짜가 함께 기록된다.

## 알아 둘 점

- ad-hoc 서명이라 `로그인할 때 자동 실행` 등록이 실패할 수 있다.
  실패하면 소리가 한 번 나고 토글이 되돌아간다.
  그때는 시스템 설정 → 일반 → 로그인 항목에 직접 추가하면 된다.
- macOS 14 이상이 필요하다.
- 패널 배경은 일부러 불투명하게 칠했다. `MenuBarExtra` 기본 재질은 반투명이라
  뒤에 있는 창에 따라 글자 가독성이 달라진다. 바꾸고 싶으면
  `ContentView.swift` 의 `chromeBackground` / `listBackground` 를 손보면 된다.
- 날짜는 이 맥의 시간대 기준 자정으로 맞춰 저장한다. 시간대를 크게 옮기면
  경계에 걸친 할 일이 하루 밀려 보일 수 있다.
- 자정을 넘겨도 열려 있던 패널은 그대로다. 닫았다 다시 열면 새 "오늘" 로 맞춰진다.
- 스크럼의 `복사하기` 는 지난 미완료를 **실제로 옮긴다.** 되돌리기는 없으니
  옮기고 싶지 않으면 체크박스를 먼저 끄면 된다.
- 공휴일은 구분하지 않는다. 월~금 범위에서 주중 공휴일은 작업일로 친다.
- 처음 열 때 Gatekeeper 가 막으면 `우클릭 → 열기` 로 한 번만 열어 주면 된다.
  ad-hoc 서명이라 공증(notarization)이 없다.
